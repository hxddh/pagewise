## 1. 唯一配得上"质变"的一件：这是一个翻页器，不是阅读器 · V44

PageWise 一次只渲染一页：

```
usePdfViewer   一个 canvas（canvasRef），一个 page
               pageTurnAnim: "next" | "prev"    ← 翻页动画
wheel-gesture  thresholdFit: 88 / thresholdEdge: 56 / minFlipGapMs: 240
               → 滚轮不是滚动，是"攒够位移就翻一页"
               → 放大后先在页内滚，滚到边缘再翻
```

**所有主流阅读器都是连续滚动的**：预览、Acrobat、Chrome、Edge、Zotero、Skim。PageWise 是唯一要你一页一页点过去的。

这不是审美问题，是**读不下去**的问题：

- 一个自然段跨页断开，你要翻页、丢失上下文、再翻回来
- 想快速扫过去找那张图，只能一次一页地点
- 对照第 12 页和第 13 页的两个数字，做不到
- 5.1 刚做的区域标记，框一个跨页的表格——做不到（这条限制我当时写进设计稿当"约束"，其实它是这个模型的症状）

而这个产品的定位是"读文档"。**阅读的基本手势是错的，其他一切打磨都在这之上。**

### 为什么它是"质变"而不是"改一个参数"

因为整个渲染与覆盖层栈都建在"一页"这个前提上：

```
preview-page-frame（单页）
  ├── canvas               一页的位图
  ├── pdf-text-layer       一页的文本层
  ├── SearchHighlight      绝对定位在这一页
  ├── MarkLayer            绝对定位在这一页
  ├── LinkLayer            绝对定位在这一页
  └── RegionSelectLayer    绝对定位在这一页
```

连续滚动意味着：虚拟化的页列表、每页各自的四层覆盖、滚动位置 ↔ 当前页号的双向绑定（缩略图、大纲、标记列表、`pagewise-page:` 引用跳转、agent 的"当前页"上下文全都依赖它）、以及 `pageCache` / `textLayerCache` 的预算要按可见窗口而不是当前页来管。

这是这几个版本里第一件**真正需要重构而不是叠加**的事。它也正好是最该做的那件。

## 2. 第二件：外壳没跟上功能 · V45

顶层覆盖面 **9 个**，预览层内再叠 **7 个**：

```
App.tsx      CommandPalette / DropOverlay / LoadingOverlay / FileErrorBanner /
             ToastViewport / ClearChatConfirm / ConfirmOverlay / RecentFilesDrawer /
             SettingsDrawer                                              = 9

PreviewPane  DocumentSearch / ConfirmOverlay / MarkNote /
             MarkLayer / LinkLayer / SearchHighlight / RegionSelectLayer = 7
```

侧栏塞了三个标签（页面 / 大纲 / 标记），工具栏多了一个模式开关，选区旁边浮两个按钮，批注卡片吊在预览底部。

**每一件单独看都放对了地方——我自己就是这样一件件加进去的。** 但四个版本加下来，外壳还是 4.x 那个"预览 + 聊天 + 抽屉"的两栏，而功能已经翻了一倍。这不是某一处的错，是**没人回头重排过**。

不过要老实说：**这一条我给不出"应该长什么样"的答案，因为我看不见它现在长什么样。** 它是一个观察，不是一个方案。

## 3. 不建议现在做的

| | 理由 |
|---|---|
| 视觉改版（配色/排版/图标） | 我评不了也做不了盲改。需要你的输入 |
| 双页对开 | 是连续滚动的下游选项，做在它之前会返工 |
| 更多快捷键 / 命令 | 命令面板已经有了；再加是在第 10 个覆盖面上加第 11 个 |
| 移动端 / 响应式 | 桌面应用，窗口尺寸有下限（900×600） |

---

## 4. 建议

**5.3 做连续滚动。** 它是唯一一件符合"质变"的：改的是这个产品最核心的手势，而不是它的外观。做完之后跨页选区、跨页标记、对照阅读、快速翻找全都跟着成立。

代价要说清楚：**这是本轮以来第一件需要重构的事**，涉及 `usePdfViewer`、`pdf.ts` 的渲染与缓存预算、四个覆盖层、以及所有依赖"当前页"的东西（缩略图、大纲、标记列表、引用跳转、agent 上下文）。不是一两个文件的改动。

如果你要的"质变"其实是**视觉**上的，那请给我几张截图或者说清楚不满意在哪——那条路我现在完全是瞎的，硬做只会做出一版你不想要的。

```

                  prevPage() / nextPage()

PreviewPane.tsx   preview-page-frame 内：canvas + 文本层 + 4 个绝对定位覆盖层
```
